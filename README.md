## Sobre mí

Soy **Ingeniero de Sistemas** especializado en **inteligencia artificial, datos geoespaciales y desarrollo full-stack**. Construyo aplicaciones de escritorio y web donde conviven agentes de IA, mapas y visualización de datos, y me gusta que el producto final se sienta **limpio, rápido y bien arquitectado**.

Además soy **creador de contenido educativo** (*Code_Clean*): comparto lo que aprendo en YouTube y TikTok para que programar sea más fácil para otros.

| | |
|---|---|
| **Enfoque** | Agentes de IA, datos geoespaciales, arquitectura de software |
| **Me gusta** | Auditar arquitecturas, planificar features y llevarlas a código funcionando |
| **Comparto** | Tutoriales y proyectos completos en video |
